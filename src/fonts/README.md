# Fontes

Duas famílias, ambas **SIL Open Font License 1.1**, em arquivos variáveis com os
subsets `latin` e `latin-ext`, baixadas do Google Fonts:

| Arquivo | Família | Papel |
|---|---|---|
| `jetbrains-mono-latin.woff2`, `-ext` | JetBrains Mono 300–700 | toda a UI: rótulos, portas, endereços, log |
| `inter-tight-latin.woff2`, `-ext` | Inter Tight 300–600 | só o estado do proxy, no talão |

Ficam no repositório de propósito: a janela é offline e a CSP do Tauri é
`default-src 'self'` — nada de CDN.
